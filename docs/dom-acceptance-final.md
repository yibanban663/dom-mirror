## 三、已知边界（非缺陷，列入 roadmap）

1. 墨提斯登录页整帧 skp 达 20MB（双 canvas 点阵 + react-flow）——A 路线 v1 对此类重页不可用，>4MB 尺寸熔断（`4ec1b86`）已保护引擎；layer-split 拆帧列入阶段 3

3. 表单输入回显 P95 6.4s——与漂移矫正队列耦合，阶段 3 解耦项

## 四、结论

三症状根因修复经服务端连续指标 + 端到端会话 + 助手实测三层验证全部生效。DOM 模式恢复为可用日用状态；A 路线（strict 通道）保留于独立开关（`XY_A_ROUTE=1`），canvas 友好页面按需启用；Metis 类重页面待阶段 3 layer-split。
