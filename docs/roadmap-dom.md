# RBI · DOM 引擎线排期（默认通道）

> 两个不同的引擎，分开做。本线是**默认通道**：镜像 DOM 在客户端本地渲染，
> 换取接近原生的输入与动效手感。DL 引擎线见 `docs/roadmap-dl.md`（strict 旁路，不替代本线）。

## 定位与北极星

- DOM 是默认模式；接不住的元素走阶段 2 旁路；整页像素只留给"文字不能出现在用户浏览器"的页面。
- 验收口径分列：**本地类交互**（悬停/滚动/组词回显）≈1 帧上屏；**服务端介导交互**按 RTT 计，不进本地口径。
- 成本线（硬门槛）：6 个静会话 ≤ **1.1 GiB 内存、0.16 核**。任何新方案不得高于此线。

## 已有基线（阶段 0 起点即资产）

快照与补丁、本地悬停与 CSS 动画、输入法 composition、二维 canvas-ops、
可开关的 WebGL 调用重放（glStream）、有地址视频走 `/m` 本地播放。

## 工程纪律

- 每阶段验收数字进看板，和阶段 0 基线同口径对比。
- 会话/重连/隔离/内存配额复用网关既有基础设施，按复用估工，不重做。
- 与 DL 线共享的地基（事件坐标回传、字体策略）在本线仓库内演进，不跨线耦合。
